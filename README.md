# School Transport Route Optimization

## Project Overview
This project focuses on optimizing school bus transportation routes using Python and data analysis techniques.

The main objective is to generate efficient school bus routes based on student locations, bus capacity, and distance information.

## Objectives
- Optimize school bus routes.
- Analyze student and bus datasets.
- Calculate distances between locations.
- Consider vehicle capacity constraints.
- Visualize optimized routes on an interactive map.

## Technologies Used
- Python
- Pandas
- NumPy
- Google OR-Tools
- Folium
- Google Colab

## Project Files

| File | Description |
|---|---|
| School_Transport.ipynb | Main Python notebook |
| student_dataset.csv | Student information |
| bus_dataset.csv | Bus information |
| distance_matrix.csv | Distance details |
| optimized_bus_results.csv | Optimization results |
| school_bus_routes.html | Interactive route map |

## Methodology
1. Collect student and bus data.
2. Preprocess the datasets using Pandas.
3. Analyze distance information.
4. Apply route optimization using Google OR-Tools.
5. Generate optimized bus route results.
6. Visualize routes using Folium.

## Expected Benefits
- Efficient bus route planning.
- Better utilization of bus capacity.
- Improved transportation planning.
- Easy visualization of school bus routes.
